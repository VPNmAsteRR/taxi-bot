# TAXIDRIVE24/7 — запуск на H1Cloud

В архиве уже лежат код, настройки и текущая база. Это **рабочий архив продавца**:
внутри есть токены и база с данными. Не передавайте его покупателю.

## Что загрузить

1. Откройте сервер в панели H1Cloud → «Файлы».
2. Загрузите архив `TAXIDRIVE24-H1Cloud.zip` в корень сервера.
3. Распакуйте архив так, чтобы `bot.py`, `admin.py` и `main.py` лежали в корне,
   рядом с `.env` и папкой `data`.
4. В разделе «Автозапуск» укажите файл `main.py` (или `bot.py`), если панель это
   спрашивает.
5. Запустите сервер и проверьте логи.

## Важно

- В `.env` уже прописаны токены, `DATA_DIR=./data` и тариф.
- В архиве лежит рабочая база `data/taxi.db`, поэтому пользователи и заказы
  сохранятся. При первом запуске база сама добавит новые поля и таблицу админов.
- Код регистрации водителя: `TAXiDrivEE` — строго с учётом регистра.
- Код админки в архиве: `TAXI-ADMIN-2026`. После проверки замените его на свой
  в `.env` и перезапустите бота.
- Админка открывается командой `/admin` в обоих ботах.
- Не запускайте одновременно старый сервер и H1Cloud с одними и теми же
  токенами: Telegram выдаст конфликт.
- Архив содержит секретные токены. Не публикуйте его и не пересылайте
  посторонним.

## Тариф

- `BASE_FARE=250` — посадка;
- `INCLUDED_KM=2` — первые 2 км включены;
- `PRICE_PER_KM=50` — каждый км сверх 2 км.

Бот не спрашивает километраж у пассажира. В карточке показывается базовая
стоимость и тариф: «250 ₽ посадка, 2 км включены, далее 50 ₽/км».

## Проверка после запуска

1. Пассажирский бот: `/start` → заказ → адреса → тариф → отправка.
2. Водительский бот: регистрация по коду → «Начать работу» → принять заказ.
3. В обоих ботах: `/admin` → `TAXI-ADMIN-2026` → статистика.
4. Завершите тестовый заказ и проверьте статистику в админке.
